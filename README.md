# 魚類調査記録アプリ

現場で獲れた魚と川の環境をスマホに記録し、**魚類データベースにそのまま取り込めるCSV**を書き出すアプリです。
インターネットが無くても動きます（地図も、先に落としておけば圏外で出ます）。

## できること（いまの版）

- 調査をつくる（河川名・地点名・日付・業務・現在地）
- **魚の調査／物理環境の調査を選べる**（物理環境だけの日にも使えます）
- 瀬淵ごとに「箇所」を切り、開始・終了の時刻を自動で記録
- 魚種を選んで尾数を入れる（昔の呼び名でも探せます）
- **1尾ずつ体長を測る**（全長・尾叉長。測る→次へ、を繰り返す形）
- **とった労力を記録する**（電気ショッカーの通電秒数・流した回数・川幅・区間の長さ・面積）
- **川の環境を記録する**（測点ごとの水深・流速、河床材7区分の割合、左右岸のカバー）
  - 測点には、記録したときに立っていた**場所（GPS）も残ります**
- **写真を撮る**（魚の記録ごと・箇所ごと・メモごと）
- 調査ごとのメモ（写真だけのメモも残せます）
- 地図で位置を直す／圏外にそなえて地図を先に保存する
- データベース取り込み用のCSV（31列）を書き出す

## 地点を登録しておく

よく行く場所は、**一度登録しておくと調査を作るときに選ぶだけ**で済みます。
ホームの「地点を登録・確認する」から。

1. 河川名を入れる → **地図がその川へ飛びます**
   - 魚類データベースにある49河川・過去の調査地点453件から場所を出しています（圏外でも動きます）
   - 表に無い川は、電波があれば地名検索で探します
2. 地図をタップして中心を決め、まわりの広さ（半径）を決める
3. 地点名を付けて登録

調査を作るときは、河川名を入れると**その川の地点が並ぶ**ので、選ぶだけで
地点名と位置が入ります。地図には
<span>●緑＝登録した地点</span>／<span>●青＝過去の調査地点</span> が出ます。

地点を消しても、すでに作った調査の名前と位置は残ります。

## 何日かにわたる調査

調査を作るときに「終わりの日」を入れると、**期間として扱えます**（例：8/16〜8/18）。

- 箇所（地点）ごとに、その期間の中から**日付を選べます**
- 日付を選ばなければ、調査のはじめの日を使います
- 今日が期間の中なら、新しい箇所は今日が選ばれます

> **データベースには日ごとに分かれて入ります。**
> 取り込み側は調査日で調査を分けるので、3日にわたる調査は3件の調査になります。
> 書き出し画面に「◯件の調査として入ります」と出ます。

## 記録のしかたを選ぶ（一般／詳細）

調査を作るときに選びます。あとから変えられます。

| | 一般 | 詳細 |
|---|---|---|
| 記録の単位 | **箇所**（瀬淵ごと） | **地点**（魚が獲れた場所ごとに点を打つ） |
| 位置 | 調査に1つ | **点ごとに残る**（GPS） |
| 点ごとに入れるもの | — | 瀬淵区分・採捕方法・水深・流速 |
| 通電秒数・距離・面積 | 入れられる | 出しません（区間の話のため） |
| 水深・流速・河床材の割合・カバー | 「川の環境」の画面で詳しく | 点ごとに1組。詳しく入れることもできます |

どちらでも、書き出しは同じ4本＋測点です。
データベース取込用CSVの緯度経度は、**どちらも調査の位置**を使います
（点ごとにすると、取り込み側で点の数だけ調査が分かれてしまうため）。

## 2つの使いかた

**現場でその場で入れる**か、**帰ってから紙の野帳を見て書き起こす**か、どちらでもできます。
「調査をはじめる」を押していなくても記録できます。

### 現場でその場で入れるとき

1. **新しい調査をはじめる** — 河川名・地点名を入れ、「現在地を入れる」を押す
2. **はじめる** を押す（GPSで歩いた道すじの記録がはじまります）
3. **箇所を追加する** — 瀬淵の区分と調査方法を選ぶ（開始時刻が自動で入ります）
4. **魚を記録する** — 魚種を選ぶ
   - **1尾ずつ測る** … 全長を打って「この1尾を記録して次へ」を繰り返します
     - 測りながら、上の並びで**魚種を切り替えられます**（「＋魚種」で足せます）
     - **まとめて入れる**：読み上げを聞きながら、全長を打って「つぎ」を繰り返し、一括で追加
       - **テンキーが出ます。** テンキーには空白キーが無いので「つぎ」で区切ります
       - 打ち間違えたら「1つ消す」で末尾を1つ戻せます
       - 1つでも読めない値があれば1尾も入りません（途中まで入るのを避けるため）
   - **数えただけの尾数** … 測らない分はまとめて入れます（測った分と足されます）
   - 「保存して次の魚種へ」で続けて入れられます
   - 電気ショッカーを流すときは、箇所ハブの**通電スタート**を押してください
5. **川の環境を記録する** — 測点（水深・流速）を何点でも。河床材の割合、左右岸のカバー
   - 水深・流速の代表値は、手で入れなければ**測点の平均**を使います
   - 測点を記録すると、そのとき立っていた場所もいっしょに残ります。
     受かりが粗いとき（±50mより悪い）や、位置が古いときは付けません
6. **この箇所を終える** — 終了時刻が入ります。次の瀬淵へ
7. 全部終わったら **終える** → **書き出す**

### 帰ってから書き起こすとき

1. **新しい調査をはじめる** — 調査した日の日付を入れる
2. そのまま **箇所を追加する**（「はじめる」は押さなくて構いません）
3. **開始・終了の時刻を手で入れる**（野帳の時刻をそのまま）
4. 魚と環境を入れる。終わった調査・終えた箇所にも、あとから足せます

> 調査日が今日でないときは、時刻を勝手に入れません。
> 今の時刻が入ってしまうと、実際の調査時刻と食い違うためです。

## 物理環境の調査

調査を作るときに「何を調べますか」で **物理環境** を選ぶと、環境だけを記録する形になります。
魚まわりの画面は出ません。

つづけて **環境の取り方** を選びます。現場のやり方が3通りあるためです。

| 取り方 | どういうとき | 呼び名 |
|---|---|---|
| **点** | 測点をどんどん打って、水深・流速を拾う | 箇所 |
| **ライン** | 早瀬・平瀬・淵…を縦断的に区間で区切って取る | 区間 |
| **メッシュ** | 範囲に格子を切って、マスごとに詳しく取る | 範囲 |

> ここで選ぶのは**新しく作るときの初期値**です。取り方は1つずつ変えられるので、
> 1つの調査の中に「区間」と「範囲」を混ぜても構いません。

### 点とラインは、地図の上で足します

物理環境の調査を開くと、**いきなり地図**が出ます。

1. 上の **P／LS／LE** で、つぎに足すものを選びます
   - **P** … ポイント（1つの点）
   - **LS** … ラインの始まり　**LE** … ラインの終わり
2. 「**いまここに追加**」を押すか、**地図をタップ**すると、そこに置かれます
3. **足した時刻は、そのつど自動で残ります**

**LS と LE は交互に入れ替わります。** LS を置けばつぎは LE、LE を置けばつぎは LS。
**P を押すか、同じものを続けて押す**と、交互をやめて同じものを続けて置けます。

LE は「まだ終わっていないライン」につながります。無いときは、その旨をお知らせします。

名前は **P1・P2…／L1・L2…** と自動で付きます。
地図の点や下のボタンをタップすると、その記録を選べます。
選んだ記録の中身は、**同じ画面の下**で入れます。

**ラインはつながります。** LE で閉じた場所が、そのまま次のラインの始まりになります。
川を歩きながら、境目で1回たたくだけで区間が続いていきます。
つなげたくないときは「つなげない」に切り替えてください。

**色分け**を選べます（環境区分／河床材料／礫の状況／流速／水深）。
地図の下に凡例が出ます。流速と水深は、小さいほど青・大きいほど赤になります。

**いまいる場所**が地図に出ます。青い丸と、その周りに「どれくらい確かか」の輪（±m）です。
歩けば追いかけます。この印は押せません（記録と間違えないためです）。

地図の上の **◎** を押すと、いまいる場所へ地図が飛びます。遠くを見ていたら寄ってくれます。

**地図に乗る記号**は、白フチの丸に文字が入った形です。
点とラインの始まりには**名前**（P1・L1）が、ラインの終わりには「終」が出ます。
いま選んでいるものは、大きく太く出ます。

**地図は勝手に動きません。** 点や線を置いても、寄って見ている場所はそのままです。
全体を見たいときは、地図の上の「**全**」を押してください。

**地図は大きくできます**（地図の上の「大」）。大きくしても、下の入力はそのまま使えます。
地図は**22まで寄れます**（地理院の地図は18までなので、そこから先は引き伸ばして表示します）。

**入れたそばから保存されます。** 保存ボタンを押し忘れても、記録に入っています
（写真も同じです）。記録を選び替えたり、次の点を置いたりする前にも、打ちかけの分は書かれます。

> ただし、**おかしな値（マイナスの水深など）があるあいだは保存を止めます。**
> 画面に理由が出つづけるので、直してください。打った内容は消えません。

「保存する」ボタンは残してあります。不安なときに押すと「保存しました」と出ます。

> 水深と流速は **m・m/s** で入れてください（例：0.25 m ／ 0.253 m/s）。
> 淀みの流速0・干出の水深0も、そのまま入れて構いません。

### ライン（区間）の取り方

区間の始めと終わりで「**いまここ**」を押してください。歩いた向き（上流→下流／下流→上流）も選べます。
**向きはどちらでも構いません。** 距離は同じように出ます。

区間の長さは、次の順で決まります。

> 手で入れた値 ＞ **押さえた始点〜終点** ＞ 歩いた跡の直線 ＞ 歩いた跡の総延長

電気ショッカーのように行き来しても、押さえた始終点があれば水増しされません。
**片方しか押さえていないときは空欄**にします（0mとは書きません）。

区間の中の水深・流速・河床材・カバーは、いままでと同じ「川の環境」の画面で入れます。
測点を打っていればそこから自動で出し、打っていなければ手で入れた代表値を使います。

### メッシュ（範囲）の取り方

1. 川の四隅を **上流の左岸 → 上流の右岸 → 下流の右岸 → 下流の左岸** の順に押さえます
   （地図をタップしても、その場で「いまここ」でも構いません）
2. **縦の間隔（m）** と **横の分割数** を入れます。何マスになるかが、決める前に出ます
3. 「この格子で決める」を押すと、格子ができます

**マスの位置は四隅から計算で出します。** 1マスずつGPSを取ると、誤差で格子から外れてしまうためです。

一覧は行×列の表です。入力したマスが緑になり、中に水深が出ます。タップで開きます。

1マスには 水深・流速・河床材のほか、折りたたみの中に 環境区分・礫の埋もれ度・カバー・
河床材の割合（7区分）・備考が入ります。
**「1つ前のマスと同じにする」**を押すと、となりのマスの中身をそのまま写せます。
**「保存して次のマスへ」**で右へ、行の終わりで次の行の左へ進みます。

> **四隅や細かさを変えると、同じ「3行2列」でも川の別の場所になります。**
> そのため、前の格子で入れたマスは新しい格子の一覧・まとめには混ぜません。
> **記録は消えません。** CSVには「前の格子のマス」として出ます。

> 上限は2000マスです。それを超えるときは、間隔を広げるか範囲を分けてください。

> **物理環境の調査では、31列のCSVは出ません。** 31列のCSVは1行が「1種の結果」で
> 種IDが要るためです。川の環境は「箇所ごとの記録」「測点ごとの水深・流速」に出ます。

## 写真

「写真を撮る／端末から選ぶ」ボタンから、その場で撮るか、端末の中から選べます。

- 付けられるのは **魚の記録（種ごと）／箇所／メモ** の3か所
- 撮った写真をタップすると大きく見られます（写りの確認に）
- **保存を押すまで、その記録には結びつきません。** ただし押す前に画面が切り替わっても消えません
- 取り込むときに自動で小さくします（長辺1600px）。端末の容量を食いすぎないようにするためです

### パソコンに取り出す

書き出し画面の「**写真をまとめて書き出す（ZIP）**」を押すと、その調査の写真が1つのファイルにまとまります。

中に「**写真一覧.csv**」が入っていて、どの写真がどの記録のものか（箇所・種・時刻・位置）が分かります。
ファイル名も `001_魚_St.1_ウグイ_1.jpg` のように、見ただけで分かる形にしてあります。

> 写真が多いと時間がかかります。おおよそ0.4GBを超えると確認が出ます。

## 書き出したCSVの取り込みかた

魚類データベースを開き、
**「資料管理」→「調査記録」→「CSV / Excel から一括インポート」**
に書き出したファイルを入れてください。

> **同じファイルを2回入れると、記録が二重に増えます。**
> 書き出した日付が書き出し画面に出るので、入れ終わったら覚えておいてください。

## 気をつけること

- **箇所の開始時刻は消さないでください。** 空だと、取り込み側が別々の瀬淵を1つにまとめてしまいます
- **エビ・カニも記録できます**（スジエビ・テナガエビ・ヌマエビ・モクズガニ）
- 水深・流速は **cm・cm/s** で入れてください。書き出すときに m・m/s に直します
- **0 は「測って0だった」として残します。** 未入力とは区別されます
- 記録はこの端末の中にだけあります。機種変更の前には書き出してください
  （**写真は記録のCSVには入りません。** 写真のZIPも別に書き出してください）
- 保存の空きは、同じ置き場にある他のアプリ（鳥・産卵床）と分け合っています。
  写真を溜めすぎると、圏外用の地図が入らなくなることがあります

## アプリを新しくする

ホーム画面の下に「**最新に更新する**」ボタンがあります。電波の届くところで押してください。

- **記録した調査・箇所・魚は消えません**
- **圏外用に落とした地図も消えません**
- 消えるのはアプリのプログラムと、地図を動かして自然に溜まった分だけです

その隣の「新しい版があるか見る」は、調べるだけで何も消しません。
いま入っている版と、配信されている版を見比べられます。

## まだ無いもの（これから）

- 1尾ずつ（個体）の写真
- 写真ごと丸ごとのバックアップ
- 集計画面、バックアップと復元、ごみ箱
- 「個体」「箇所」「調査」のCSVをデータベースに取り込む口
- データベースへの直接送信

## 開発者向け

- 本体は `fish_survey.html` 1つ。ビルド工程はありません
- 魚種リストは**自動生成**。手で書き換えないでください
  ```
  cd 魚類データベース
  python scripts/generate_fish_app_species.py          # 作り直す
  python scripts/generate_fish_app_species.py --check  # ずれていないか見る
  ```
- 動作の確認（ブラウザが要ります）
  ```
  cd 魚類調査アプリ
  node tests/run_all.js
  ```
- 手元で開く（`file://` では動きません）
  ```
  python -m http.server 8766
  # → http://127.0.0.1:8766/fish_survey.html
  ```
- 版を上げるときは `fish_survey.html` の `APP_VERSION` と `sw.js` の `CACHE` を
  **両方**そろえてください（ずれていると `tests/smoke.test.js` が落ちます）
